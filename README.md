# LA · Lage-Achse · 6D · Position

LA ist das Achsenmodul des Systems.
Es definiert die sechs Grundachsen, die jede Lage bestimmen.

LA ist die Basis für:
- LAGE (Positionsmatrix)
- GE (Geometrie)
- RAUM (Viewer)
- ROOM (Engine)
- ULTRA3.0 (Meta-System)

---

# 1. Aufgabe von LA

LA liefert die sechs Lageachsen:

X = horizont  
Y = breite  
Z = tiefe  
U = ultra  
V = wert  
W = mystery  

Diese Achsen bilden die **6D-Lage**.

---

# 2. LA und LAGE

LAGE nutzt LA als Achsenquelle.

LA = Achsen  
LAGE = Position

Ohne LA kann LAGE keine Position berechnen.
